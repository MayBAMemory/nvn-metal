# K02 导入符号与 D2R 接管对照

日期：2026-10-14。状态：完成。

## 做了什么

从三个映像重新导出动态符号；用 LLVM cxxfilt 还原名称；扫描 dm/host 和 dm/gfx 的 C 宏登记，忽略注释。生成两份导入表及一份反向 HLE 对照表。

defined_in 按导出表的精确 mangled 名称匹配，多提供者以分号分隔。d2r 保留所有登记类型和文件，未接管时 d2r 为空、d2r_file 为 -；仅核对接口名称，尚未验证卡比所需的运行时语义。ns 默认取前两级，detail 保留第三级，其余 C 名称归 libc。

## 复现

```powershell
scoop install llvm
python -I kirby/tools/imports_compare.py --images D:\kirby-work\img --symbols D:\kirby-work\symbols --llvm-cxxfilt C:\Users\hy367\scoop\apps\llvm\current\bin\llvm-cxxfilt.exe
```
